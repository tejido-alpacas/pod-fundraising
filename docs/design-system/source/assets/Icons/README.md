# Icons

Tejido's interface icons: 24×24, 1.75 stroke, round caps and joins. These files are single-ink in `#16212b` (`text-primary`, light) for reference and download. In the product, draw icons inline with `currentColor` (`svelte/Icon.svelte`, `svelte/icons.ts`) so they take the colour of their tone.

- **Filing:** `receipt-check`, `receipt-clock`, `receipt-flag`, `receipt-missing`, used only for filing and receipt states.
- **Milestone:** `ms-not-started`, `ms-in-progress`, `ms-claimed` (dashed), `ms-confirmed` (seal), `ms-overdue`, used only for milestones.
- **Confirmation:** `conf-participant`, `conf-stakeholder`, `conf-independent`, used only for who confirmed.
- **Evidence:** `image`, `file-text`, `upload`, `sync`, `device`, `eye`, `eye-off`, `excluded`, `camera`, `paperclip`, `hash` (file fingerprint).
- **Deposit:** `deposit`, `return`, `clock`.
- **General:** people, places, feedback and navigation.
- `weave` is the brand mark (see Brand).
