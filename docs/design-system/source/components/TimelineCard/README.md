# TimelineCard

One filed entry, woven onto the campaign timeline.

- **Provide:** the entry, its milestone, the filer (name and role), the deposit, the proof link, a short human title (or the first sentence of the summary) and the number of excluded files.
- **Anatomy:** a node on the thread showing the filing state (receipt shapes), then a card with kicker (item · milestone), title, filer and time, filing badge, the filer's words, facts (period, "35% complete, as reported", "Reported as delayed"), thumbnails including excluded tiles, the reason box for flagged or incomplete entries, and a footer with the deposit state and **View proof**.
- **Variants:** verified, pending, flagged (critical border and reason), incomplete (attention border and reason), confirmation (seal node, strength inline), and system events (overdue, open question), which sit on the thread without a card.
- Group entries under date headings, newest first. Show percentages only as the reporter's own figure.
