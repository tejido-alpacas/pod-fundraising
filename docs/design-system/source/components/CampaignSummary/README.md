# CampaignSummary

The top of a campaign: what it is, for whom, by whom, where, with one real project photo.

- **Provide:** category, place, start date, title (serif `text-title-1`/`text-display`), beneficiary, organizer, photo with a caption (what it shows, who filed it, when) and the summary (`text-lede`).
- The photo must be a filed project photo, not stock or a portrait.
