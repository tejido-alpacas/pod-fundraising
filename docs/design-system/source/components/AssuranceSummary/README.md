# AssuranceSummary

*Intentional addition.* The three trust questions, answered separately: was the filing recorded correctly, is there evidence, and has someone confirmed it.

- Use it on the proof page and the milestone page, directly after any banner and before the details. This is the clearest place where Tejido refuses to merge three facts into one checkmark.
- **Provide:** three items, each with a tone, an icon, the question, a short answer ("Recorded, but flagged", "1 photo, 1 file left out", "Not yet") and one sentence.
- Stacked on phones, three columns from 760px.
