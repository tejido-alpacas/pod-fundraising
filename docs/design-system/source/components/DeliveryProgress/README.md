# DeliveryProgress

Work delivered: one segment per milestone, counted and never expressed as a percentage.

- **Provide:** the milestones with their status and overdue flag.
- **Segments:** confirmed is solid, claimed is dashed, in progress is hatched in progress blue, overdue is hatched in critical with a notch, not started is an empty `border-strong` outline. Show the legend wherever the track appears without its milestone list.
- **Headline:** "1 of 5 milestones confirmed". Only confirmed milestones count as delivered.
