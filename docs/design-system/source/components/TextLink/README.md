# TextLink

Inline and standalone links.

- Inline links (`a`, `.tj-link`) are `link`, underlined with a 1px line at a 3px offset, thickening to 2px on hover.
- Standalone links (`.tj-link--standalone`) are semibold, 44px tall and carry a trailing arrow, for example *View proof* or *View milestone*. Use them at the end of cards.
- Links to the public ledger or other sites carry the `external` icon and open in the same tab unless the person is mid-task in the field app.
- Never use a link for an action that changes data. That's a button.
