# MilestoneRow

A milestone in a list, linking to its detail page.

- **Provide:** position, title, owner, status, a `when` line, days overdue and the confirmation strength once confirmed.
- The number circle carries the status shape: solid when confirmed, dashed when claimed. Badges go under the title on phones and to the right from 640px.
- Use inside `.tj-msrows`, which draws the outer border and dividers. Don't nest the list in another card.
