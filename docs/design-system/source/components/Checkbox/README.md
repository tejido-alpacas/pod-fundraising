# Checkbox

A checkbox and the radio choice card, both with 44px rows.

- **Checkbox** (`tj-check`): independent yes/no items, such as checklist items before confirming or the milestones a confirmer covers. Use the label as the statement, with an optional hint below.
- **Choice card** (`tj-check tj-choice` with `type="radio"`): one choice among a few options that each need a sentence, such as the confirmer's relationship to the project. The selected card shows an `accent` border and an `accent-subtle` fill.
- Group related options in a `fieldset` with a `legend`.
