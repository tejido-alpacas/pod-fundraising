# MobileNav

Navigation on phones: the field app's three-tab bar and the public site's menu sheet.

- **Field tab bar:** Log work, My entries, Milestones. 56px tall, sticky. The current tab has an `accent` top rule and colour. Hide it inside task flows (chat, evidence, review), which use a back button instead.
- **Public menu sheet:** a bottom sheet (`radius-xl`, `shadow-2`) with 52px rows.
