# SelectField

A native select with Tejido's border, height and chevron.

- Use it for choosing among 2–15 known options, such as the milestone, the kind of milestone or the party. Use choice cards (see `Checkbox`) when each option needs explaining.
- Keep it native for mobile pickers and accessibility. Don't build a custom listbox.
- Option text matches how the item appears elsewhere: "2 · Walls up to roof height".
