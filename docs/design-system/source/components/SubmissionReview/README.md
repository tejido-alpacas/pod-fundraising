# SubmissionReview

The last step before filing: what will be filed, what it costs, and what happens next.

- **Anatomy:** title, lifecycle steps (Drafted → Uploaded → Submitted → Recorded → Confirmed) with the current step and a plain line ("Step 3 of 5 · Next: you file it with Tejido"), key/value summary, the deposit and when it comes back, then **File this entry** and **Change something**.
- Below 480px the step names are visually hidden and the line names the current step. Screen readers still get every step.
- After tapping File: the button shows "Filing…", then a tool result "Submitted at 16:48. Waiting for the public receipt." It never shows a success state before the server answers.
