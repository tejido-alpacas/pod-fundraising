# FundingProgress

Money raised against the goal: a continuous ink bar with a percentage.

- **Provide:** raised, goal, contributions and whether the campaign is still open.
- The fill is `funding` (ink) on `bg-sunken`, never a status colour. `role="progressbar"` with `aria-valuetext` in words.
- Always place it next to `DeliveryProgress`, never alone after funding opens.
