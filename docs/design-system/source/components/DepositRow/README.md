# DepositRow

The filing deposit on an entry or milestone, with what it is and what it isn't.

- **Provide:** amount (from `formatAmount`), state (held, refunded or refund outstanding) and a sentence.
- Every full deposit row says it isn't a donation: "Paid by the filer to record this entry. Returned when milestone 2 is confirmed. It isn't a donation or a payment for the work."
- Never write "refunded" without "deposit".
