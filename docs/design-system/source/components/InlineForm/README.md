# InlineForm

A compact structured form inside an assistant message for quantity and unit, amount and currency, date, milestone and description.

- Pre-fill from what the person said. Ask only for what's missing.
- Two columns from 520px, stacked below. Inputs keep full size: 16px text and 44px height.
- Saves to the device on every change and shows "Saved on this phone at 16:45" after the write. It never files.
